# Skyline Weather App

## 📌 Project Overview

Skyline Weather App is a responsive weather application built using React and Vite. It allows users to search for any city and displays real-time weather information using the OpenWeather API.

---

## ✨ Features

- Search weather by city name
- Current temperature
- Weather condition
- Feels like temperature
- Humidity
- Wind speed
- Pressure
- Visibility
- Sunrise & Sunset timings
- Responsive user interface

---

## 🛠 Tech Stack

- React
- Vite
- JavaScript
- CSS
- OpenWeather API
- Git
- GitHub
- Vercel

---

## 🚀 Installation & Local Setup

```bash
git clone https://github.com/sanjayraj-git/weather-app.git
cd weather-app
npm install
npm run dev
```

Create a `.env` file and add:

```env
VITE_OPENWEATHER_API_KEY=your_api_key
```

---

## 📌 Assumptions

- Internet connection is required.
- Users must enter a valid city name.
- A valid OpenWeather API key is required.

---

## ⚠ Known Limitations

- Shows only current weather information.
- Invalid city names return an error.
- Weather data depends on the OpenWeather API.
